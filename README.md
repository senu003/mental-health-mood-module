# Mental Health Mood Module

A multi-platform mood and mental-health support system developed as part of a university project.

The repository contains the main web application, backend API, and an independently developed mobile application prototype.

## Project Structure

```text
mood-se/
├── mood-backend/   # Backend API
├── mood-module/    # Web application
└── myApp/          # Mobile application prototype
```

## My Contribution

In addition to working on the main project, I independently explored and developed a **mobile application prototype** using React Native and Expo.

The mobile application was developed separately during the project and was not included in the final team version. It remains in this repository as part of my individual technical work and experimentation.

## Repository Structure

Each application is maintained as an independent project with its own dependencies and configuration.

Install and run commands should be executed inside the relevant project directory.

## Running the Projects

### Backend

```bash
cd mood-backend
npm install
npm run dev
```

### Web

```bash
cd mood-module
npm install
npm run dev
```

### Mobile Prototype

```bash
cd myApp
npm install
npm run start
```

Then use Expo Go or an emulator to run the application.
